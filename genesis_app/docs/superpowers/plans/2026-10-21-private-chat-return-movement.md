# 私聊返回地点的角色移动展示

用户已批准：私聊内不显示移动卡片；返回地点后对比私聊前后的真实位置，复用现有移动卡片。只在地点页面内展示，不写入聊天存储或 History。

## 实现步骤

- MiniPhone 实际进入正式私聊时通知调用页面；仅打开其他手机应用不启动比较。
- LocationChat 记录位置、账号、地点、公开聊天/Tick 边界。返回时读取当前世界快照，并复用已有刷新入口补一次查询。
- 同一段私聊的角色 A→B→C 只显示最终去向；回到原位不生成卡片。只展示离开/进入当前地点的角色。
- 等待期间的位置更新补到同一张视图卡。新地点发言、公开聊天推进或 Tick 开始后停止对比，已有正式移动卡优先，避免重复。
- 账号/地点/服务变化时清空本地展示；不修改正式移动事件解析、私聊内容和 History。
- 格式化实际文件，运行静态检查；本轮不新增或运行测试。热重启已有 Debug 会话，不打包或推送。
