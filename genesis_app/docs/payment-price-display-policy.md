# 支付价格展示规则

订阅和 Gems 使用同一规则，根据商店返回的 ISO 币种码选择页面价格来源：

- EUR、GBP、AUD、CAD、JPY、TWD：使用商店金额、币种及格式化价格。
- USD 及其他币种、商店价格缺失：使用服务端配置的金额和币种。
- 年缴折合月价和折扣使用选定展示来源的金额计算。
- 日元、韩元折合月价不显示小数；新台币沿用商店报价有无小数的精度，折合价格按对应精度四舍五入。
- 商店来源的年缴折合月价保留商店报价的币种前缀/后缀、空格和小数格式，例如 CA$139.99 折合 CA$11.67/月，不简化为 $11.67。

商店查询、内存与磁盘缓存继续保留完整商店报价，币种筛选只影响展示。
StoreKit 2 的币种码取商品 `priceFormatStyle.currencyCode`，不取格式化 Locale 的默认币种；币种符号使用商品币种和该 Locale 生成。商品原始金额和 `displayPrice` 原样保留，不按 storefront 或系统语言换算。此规则修正币种元数据读取，不能修正 StoreKit 自身返回的错误金额或价格文本。
订阅和 Gems 展示价格去掉全零小数（.00 或 ,00），非零小数、币种标识和位置保留；原始报价与扣款数据不变。
订阅方案金额、年缴说明、底部购买按钮及 Gems 商品价格超长时缩小显示，保留完整金额和币种，不使用省略号。
购买前仍须查询有效商店商品；展示价格或商品/offer 身份变化时需再次确认。
Gems 对非白名单币种比较服务端展示金额和币种，不因隐藏的商店金额变化要求再次点击。
原生购买弹窗和实际扣款始终由商店决定，可能与服务端展示价格的币种和金额不同。
