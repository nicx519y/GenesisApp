# MiniPhone 相机接入（2026-11-04）

接口来源：[服务端对接文档](mini-phone-camera-api-2026-11-04.md)。本文记录客户端行为；不表示真实后端计费、推送或设备体验已验收。

## 接口与所有权

- `GenesisApi.miniPhone` 复用既有 Chatroom HTTP 客户端、认证、语言、签名和公共业务错误处理。`cameraOptions` 请求 `phone/photo/options`；`createCameraPhoto` 请求 `phone/photo/create`，不引入第二套传输或超时调度。
- 创建正文只有 `client_request_id/world_id/character_ids/aspect_ratio/style` 与非空时的 `prompt`，不传价格或免费资格字段。最多选择四个真实 World 角色；描述可空，五种既有比例默认 2:3；风格展示服务端 name，发送 label。
- 底部角色条将 World Detail 中 `player_uid` 匹配当前账号的角色放到最左侧，其余角色保留原相对顺序。这一排序仅应用于底部角色条，拍照请求仍沿用原角色顺序。
- `PhotoTask` 保存共享三态、真实图片和结构化失败。聊天解析仍严格要求聊天消息 ID；camera 解析不要求该字段。ID 不经过浮点数。
- World 的 `MiniPhoneStore.cameraTasks` 持有任务，`MiniPhoneCameraController` 仅持有草稿。正式入口不使用模拟任务队列。关闭相机、相册或手机不取消已提交任务；World 释放停止监听，原请求日志仍保留。
- 相机复用 World 会话的 [生图超时监控](mini-phone-collect-events.md#photo-generation-timeout)。关闭手机继续计时，退出 World 停止计时。
- 复用 `phone-writes` 日志，按环境、账号和 World 隔离，保存完整原请求及照片状态。相机请求不会进入普通聊天发送锁、候选回复、History 或地点分页水位。
- 相机所有网络图片统一按 DPR 2 构建 CDN 缩放 URL：角色头像、风格入口、相册入口和风格 Sheet 示例图按实际固定展示宽度 × 2 请求；取景框 World 封面与结果图按布局宽度 × 2 匹配公共阶梯尺寸。URL 使用公共构建入口，替换旧 OSS 处理参数并保留其他参数；不改写任务、风格、相册或发帖中保存的原始 URL，结果图与大图来源预览使用相同缩放 URL。本地资源沿用本地加载。

## 提交、费用与失败

每次进入 MiniPhone 时后台刷新一次 options，更新当前环境、账号、World 的内存配置缓存；缓存字段为 world_id、price_cent、free_status 和完整 styles（name/label/demo_image_url），不新增磁盘持久化。同次打开手机期间，进入相机、点击快门和提交完成均不再请求 options。有可用缓存时立即复用，正在进行的刷新不阻塞相机或拍照确认/提交；刷新失败保留原缓存。首次没有有效缓存时禁用快门，可通过风格入口主动重试加载；读取失败仅在相机当前可见时走公共提示。账号切换清理旧配置并为新账号刷新，迟到响应不得写入新账号。说明 Sheet 展示缓存中整数 cent 格式化的基础价及免费资格；提交时服务端最终判定价格及资格。确认偏好按环境、账号、价格和免费状态保存，与聊天及旧预览布尔值隔离；报价或免费状态改变重新确认。

相机页面底部不显示基本价格，也不为价格行占位；拍照确认弹窗仍展示费用。底部从首帧保留完整本地化免费资格说明的空间，说明按当前宽度和系统字号自然换行。说明区域下方留白为 8 逻辑像素，系统底部安全区另行保留。免费说明仅在服务端确认可用时显示；资格不可用时仍保留该说明的布局空间。风格/相册入口名称固定预留两行高度，避免 options 异步返回、资格/价格刷新、风格名称换行或任务数量更新后撑高底部、挤小取景框。

风格与相片比例的选中值独立保存到设备本地 SharedPreferences，全局共用一份记录，不按环境、账号或 World 隔离，不持久化 options 的费用、免费资格或风格目录。首次 options 成功后保存首个风格的 label 和默认 2:3；再次进入优先恢复本地选择，并用最新 options 校验风格。手动切换立即更新本地记录，连续操作按字段串行保存最后选择；options 后台刷新不覆盖有效选择，也不覆盖恢复期间的新选择。服务端移除原风格时回退到当前首个可用风格并保存，风格显示名称和示例图始终来自当前 options。比例恢复同步到相机显示与拍照请求；关闭手机、退出 World 或应用重启后仍可恢复。每次进入相机重新读取，已有 World 会话也采用其他 World 最近保存的选择；迟到 options 在应用前重新读取，避免覆盖其他 World 的新选择。账号切换丢弃旧响应与恢复回调，全局偏好继续保留。

风格 Sheet 点击后先更新 item 的选中边框和选中语义，短暂停留后再收起并应用选择。存在未完成相机请求时，右下角相册缩略图保留暗色遮罩及 loading 圆环；相册中服务端 `generating` 任务以圆环和生成中文字展示，成功或失败后移除圆环。提交结果尚未确认的相册占位继续显示问号和待确认文案，不将其判作失败。

快门只在提交期间防重，受理后允许继续拍照。受理触发飞入相册反馈；后台任务成功不自动切换用户当前页面。请求先持久化再发出；保存失败不发送。普通 HTTP 超时、断线、损坏响应只留下待确认记录，不判定生成失败；未改参数再次点击快门使用原请求键、完整正文。改参数属于新拍照，旧任务仍可收到结果。没有定时任务查询或自动重发。

HTTP `1001/2061` 明确拒绝，保留草稿、不创建失败任务卡片；`10001` 沿用全局会话失效；`2062` 持久阻止以新请求键绕过同一参数冲突。余额业务码走公共充值处理。未知业务错误只显示服务端用户文案或本地化通用提示，不显示技术诊断。外层 err_no=0 后仍检查照片 status。

任务按 task_id 合并，以请求键关联原提交；结果先到、空请求键、重复事件、HTTP 迟到均不增加同一任务的卡片。终态不回退到 generating。未知在线任务可以保存真实结果身份，但不虚构可提交正文。

## 相册、恢复与通知

- 相册使用同一个三列网格连续排列相机任务占位、成功照片和其他照片，不按来源另起一行；定位和续页边界按合并后的格子索引计算。任务记录提供生成中、待确认及失败占位；不显示虚构进度、重新生成按钮或退款到账承诺。失败用 failure.message；本次相册停留中保留，离开重进隐藏旧失败，记录不删除。恢复时旧失败同样隐藏。
- 成功任务在正式相册返回前提供真实资产展示；正式资产按 asset_id 合并替换，URL 去重保留资产别名映射。正式入册确认写入请求日志，后续相册缓存页被清理时不重新将旧结果插到顶部。图片下载失败不改变任务成功状态。
- 进入、重连和前台恢复利用既有 Inbox 通知查询校准已知未完成任务。成功以通知提供的 task_id/asset_id 关联相册，失败使用通知文案；不根据时间、描述或相似 URL 猜测身份。受理不明且没有 task_id 的请求仍等待实时结果或原请求主动重试。
- `phone.photo.result` 按 source 分流，仅 camera 进入手机任务。统一 World 结果展示按 event_id 去重，仅当前账号、原 World 前台实时展示；成功和失败复用 `GenesisPushBanner`，与 New Location / New Character 共用顶部毛玻璃横幅和进出动画，默认 5 秒自动收起，也可点击提前收起，不阻断页面操作。World 所属手机及其透明浮层可见时横幅仍在根 Overlay 展示；后台、会话释放或账号切换移除当前横幅。离线、后台、离开 World 后不补弹；恢复和 Inbox 阅读不弹结果或充值面板。
- 本人实时 insufficient_balance 与公共余额面板串行，按任务去重。余额、退款、免费资格均由服务端决定。
- Inbox 两种照片通知无审核按钮；失败行没有点击回调或可点击语义，已读不依赖点击。成功行携带类型化相机目标；obj_id 仅为任务 ID。
- 成功目标打开原 World 的 Photos。优先复用已加载资产，缺失时沿 rn=100 的连续页查找，不使用不存在的资产详情接口；定位期间暂停普通滚动补页。等待实际布局后定位目标行、通过共享来源锚点自动打开大图一次，关闭保持相册位置。用户拖动、离页或身份变化取消；未找到或无权限结束定位并提示。
- 大图“用于发帖”把真实 URL 带入独立正式草稿，不覆盖已有普通发帖草稿，不重新上传、不自动发布。
- 相册大图不显示图片名称或描述；底部按“用于贴文”按钮、16 逻辑像素间距、圆点指示器排列，内容按实际高度占位并保留底部安全区。单张照片隐藏圆点。首页和相机入口关闭大图都只返回图片列表，重复关闭不得退出下层页面；从相机进入的列表再次返回才回到相机。 Android 系统手势返回先关闭根部大图，保留列表；取消手势继续停留大图。共享深色路由在任一外层路由被覆盖时禁用底层返回手势，避免内部相册先退出而大图残留。
